# GameRE-Toolkit

> 使用 AI 辅助逆向分析游戏引擎，并构建对应的分析工具。

## 📖 项目简介

本仓库主要用于存放我个人在**游戏逆向工程**学习与实践过程中，结合 **AI 辅助分析能力**所开发的一系列工具与脚本。

核心目标是利用大语言模型（LLM）与静态/动态分析手段相结合，帮助快速理解游戏引擎内部逻辑、数据结构与调用流程，并最终产出可用于调试、分析或自动化测试的辅助工具。

## 🧠 设计思路

- 使用 AI（如 GPT / Claude / 本地部署模型）辅助解析反编译代码（IDA / Ghidra / dnSpy 等）
- 对重复性的分析模式进行抽象，形成可复用的分析脚本
- 将分析结果转化为结构化数据，供后续工具链使用


## 🚀 使用前提

- 基础的游戏逆向工程环境（如 IDA Pro / Ghidra / dnSpy / Frida 等）
- Python 3.8+（大部分脚本基于 Python 开发）
- AI API 密钥（如 OpenAI / 其他兼容 API），或本地部署模型
